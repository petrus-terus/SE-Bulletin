# Sabah Electricity Internal Bulletin App

A mobile-first corporate communication Progressive Web App (PWA) for **Sabah Electricity Sdn. Bhd.** (formerly SESB).

## Documentation & Project Memory
- **Rules & Memory Context:** [`GEMINI.md`](./GEMINI.md) — Automatically ingested by the AI assistant in any session opened in this directory.
- **Full Architecture & Spec Blueprint:** [`PROJECT_SPEC.md`](./PROJECT_SPEC.md) — Exhaustive requirements, design system tokens, database ERD, API endpoints, and RBAC matrix.

## Quick Summary
- **Frontend:** React + Vite PWA (`#1A7A5A` Forest Green & `#0055A4` Deep Blue, 393x852 iPhone baseline)
- **Backend:** ASP.NET Core 8 Web API + SignalR
- **Database:** SQL Server / PostgreSQL
- **Storage:** On-premise internal SESB storage mount
- **Auth:** Corporate `@sesb.com.my` email + 6-digit OTP
- **Phase 1 Target:** Wisma SESB HQ Staff (Kota Kinabalu)
